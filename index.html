Database Kurikulum

Urutan, kelompok, nama, dan JP di sini dipakai semua format transkrip (3 Bahasa, GPA, Rapor). JP = SKS.
Nomor diurutkan ulang otomatis saat disimpan (Umum → Peminatan → Kekhasan). Kode kosong = dicocokkan dari nama mapel.

Template Dokumen

Unduh DOCX → ubah tampilan di Word (biarkan token <<…>> dan [[…]]) → unggah lagi. Langsung dipakai untuk generate berikutnya.
TemplateStatusAksi
Aturan token: <<Nama_Siswa>> diganti nilai; baris tabel yang berisi [[RAPOR.MAPEL]], [[S1.MAPEL]] atau [[P1.MAPEL]] diulang per mapel; [[RAPOR@GRUP.NAMA]] = baris judul kelompok; [[RAPOR.NO]] = nomor urut. Token tabel wajib ada — template yang tidak lolos uji ditolak dan template lama tetap dipakai. File template bisa juga langsung diseret ke kotak unggah di langkah 1.
